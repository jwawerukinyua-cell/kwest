# Authenticity

KWEST exists to represent real neighbourhoods, real businesses and real people.

Whenever possible:

- Use real photography instead of AI-generated imagery.
- Use actual business information rather than placeholder content.
- Feature real community stories after review and verification.
- Document real places that residents recognize.
- Build trust through authenticity, not visual effects.

Placeholders may be used during development, but before production they should be replaced with authentic local content whenever practical.
