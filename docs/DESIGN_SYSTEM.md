# KWEST DESIGN SYSTEM

># KWEST DESIGN SYSTEM

> Every neighbourhood has a story.
>
> KWEST exists to help residents discover, trust and support the people and businesses around them.
>
> This Design System protects that experience.
>
> It is not a collection of colours and components.
>
> It is a promise that every page, interaction and feature will feel familiar, trustworthy and unmistakably local.
---

# 1. Design Philosophy

KWEST is calm.

KWEST is trustworthy.

KWEST is familiar.

KWEST feels local before it feels digital.

Every interface should help residents make better decisions with less effort.

Technology should disappear behind clarity.
---

# 2. Design Principles

Feedback exists to help businesses improve.

Never design experiences that encourage public shaming.

The goal is a stronger community, not louder criticism.

Whenever possible,

choose local language,

local imagery,

local landmarks,

and authentic community context over generic alternatives.
---

## Trust Through Consistency

Buttons, cards, badges and typography should behave consistently across the platform.

---

## Simplicity Wins

Empty space is intentional.

Do not fill every area.

Good design allows the interface to breathe.

---

## Mobile First

Design for the phone first.

Desktop enhances the experience.

---

## Authenticity

Real places.

Real people.

Real businesses.

Real photography.

No AI-generated imagery in production whenever authentic photography is available.

# 5. Buttons

KWEST has only three button styles.

## Primary

Purpose

Main action.

Examples

- Browse Directory
- Join the Directory
- Read Story

Style

- Emerald background
- White text
- Rounded-xl

---

## Secondary

Purpose

Alternative action.

Examples

- Learn More
- View Business

Style

- White background
- Slate border
- Slate text

---

Purpose

Examples

- Close

Style

---

# 6. Cards

Cards should have:

- Rounded corners
- Light border
- Soft shadow
- Generous spacing

Cards should never feel cramped.

---

# 7. Verified Badge

The KWEST Verified Badge represents trust.

Design

- KWEST icon
- VERIFIED label
- Emerald background
- Rounded pill
- White text

The badge should appear only after verification.

It must never be used decoratively.

---

# 8. Photography

PPhotography should make residents recognize home.

Preferred order

1. Authentic local photography

2. Team photography

3. Placeholder during development

Avoid generic stock imagery whenever authentic alternatives exist.

---

# 9. Icons

Icons support content.

Icons do not replace content.

Icons should be consistent throughout the platform.

---

# 10. Motion

Motion should communicate.

Never distract.

Animations should be:

- Fast
- Subtle
- Purposeful

Hover effects should feel natural.
Motion should reward interaction.

Never demand attention.

---

# 11. Spacing

Whitespace improves readability.

Never add elements simply because space exists.

Every section should breathe.

---

# 12. Accessibility

Every interactive element must be accessible.

Requirements

- Proper contrast
- Keyboard navigation
- Focus states
- Alt text
- Semantic HTML

Accessibility is part of quality.

---

# 13. Copywriting
Write like a helpful neighbour.

Not like a corporation.

Write for residents.

Use simple language.

Avoid corporate jargon.

Every sentence should answer a question or help someone make a decision.

---

# 14. Trust Indicators

KWEST communicates trust through:

- Verified badge
- Accurate information
- Review dates
- Real photography
- Transparent updates
- Clear contact information

---

# 15. Components

Reusable components include:

- Header
- Footer
- Hero
- Category Card
- Business Card
- Story Card
- Community Update Card
- Buttons
- Verified Badge
- Search Bar

Every new component must answer one question:

Can this be reused elsewhere?

If yes,

make it reusable before shipping.

Components should never be duplicated unnecessarily.

---

# 16. Before Shipping

Before any feature is released ask:

✓ Does this reduce noise?

✓ Does this help someone decide faster?

✓ Is it mobile friendly?

✓ Is it visually consistent?

✓ Is it trustworthy?

✓ Would we proudly show it to a Kahawa West resident?

If any answer is "No",
the feature is not ready.
