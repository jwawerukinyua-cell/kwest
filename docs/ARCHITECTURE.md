## Design Rules

Components must remain reusable.

Business logic belongs inside lib/.

Static data belongs inside data/.

Documentation belongs inside docs/.

---

## Long-term Goal

Every neighbourhood should be able to use the same architecture simply by changing the business dataset.

KWEST is not building another directory. We are building digital infrastructure for neighbourhood commerce.
